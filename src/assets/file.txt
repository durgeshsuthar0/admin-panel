LinkedIn Post (Long Version):

🚀 I just built a fully responsive Admin Panel using React + Vite + Tailwind CSS — and I'm genuinely proud of how it turned out.
Most admin panels I've used are either too heavy, too ugly, or a nightmare to customize. So I decided to build one from the ground up — clean, fast, and developer-friendly.
Here's everything that's baked in 👇

🎨 UI & Design
→ Clean minimal design with DM Sans typography
→ Smooth light & dark mode toggle (saved to localStorage — no flash on reload)
→ Custom brand color system via Tailwind config
→ Consistent border radius, spacing & shadow system throughout
🗂️ Sidebar Navigation
→ Fully collapsible sidebar with smooth 300ms transition
→ Nested nav items with expand/collapse animation
→ When collapsed — hover any icon to see a flyout panel with all sub-items, fully clickable
→ Active link highlighting with brand accent color
→ Section labels (MAIN / SETTINGS) that hide gracefully when collapsed
📱 Fully Responsive
→ On mobile: sidebar becomes a slide-in drawer with backdrop overlay
→ Hamburger menu in the header opens/closes the drawer
→ Stats grid reflows from 4 columns → 2 columns → 1 column
→ Every card, table, and activity feed adapts to any screen size
📊 Dashboard Content
→ 4 stat cards with live sparkline graphs and % change indicators
→ Top Performing Posts table with revenue and trend data
→ Recent Activity feed with avatars, names, and timestamps
→ Income summary bar (Earnings / Refunds / Declines / Payouts)
🔧 Developer Experience
→ Clean component-based architecture — easy to extend
→ ThemeContext with React Context API — no extra library needed
→ All nav items defined in a single config array — add pages in seconds
→ Zero unnecessary dependencies — just React, Vite, Tailwind & Lucide icons

This took me a while to get right — especially the collapsed flyout menu and making sure the tooltip never rendered behind the sidebar (had to use ReactDOM.createPortal for that 👀).
The kind of thing that looks simple but has a lot of small details that matter.
